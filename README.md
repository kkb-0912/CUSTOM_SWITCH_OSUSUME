# 커스텀 스위치 아카이브 (Custom Switch Archive)

커스텀 키보드에서 사용되는 커스텀 스위치들의 소재·스펙·타건 특성을 정리한 데이터베이스입니다. 국내(한국) 커스텀 키보드 커뮤니티와 판매처 정보를 함께 반영해, **어떤 스위치를 어디서 구매할 수 있는지**까지 확인할 수 있도록 만들었습니다.

**🔗 라이브 데모:** https://claude.ai/artifact/Vc2JSKB5KLD1zaDcj79GpP

## 개요

- **등록된 스위치 수: 413종**
- **국내 판매 확인/언급 항목: 130개**
- 검색·필터(브랜드/타입/국내 판매 여부)·정렬이 가능한 스위치 DB 테이블
- 조건(타입·바닥압·정숙성·매끄러움·브랜드)을 입력하면 점수화해 추천해주는 "추천 도우미"
- 참고 자료: 프랑켄 스위치, 스테빌라이저, 윤활제, 소재별 특성 비교표, 제조사 소개, 국내 벤더 디렉토리

모든 별점(접점부/스템 워블/서걱임/볼륨)은 **Cherry MX Black을 기준점**으로 매겨진 상대 평가입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 스위치 아카이브 웹 페이지 (브라우저에서 바로 열어서 사용 가능) |
| `data.js` | 위 페이지가 불러오는 데이터 파일 (`window.SWITCH_DB`) — `index.html`과 같은 폴더에 있어야 정상 작동합니다 |
| `스위치_아카이브.xlsx` | 동일 데이터의 오프라인 편집용 엑셀 버전 (스위치 DB/프랑켄/스테빌라이저/윤활제/소재별 특성/제조사 소개/국내 벤더, 총 7개 시트) |
| `switch-database-notes.md` | 작업 노트 — 데이터 출처, 리서치 방법, 세션별 작업 이력, 한계점을 정리한 문서 |

## 사용 방법

`index.html`과 `data.js`를 같은 폴더에 두고 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다. 별도의 서버나 빌드 과정이 필요 없는 순수 HTML/CSS/JS 정적 페이지입니다.

## 데이터 출처

- 기계식키보드 마이너 갤러리 정보글 & 스위치 데이터 문서 (커뮤니티 위키)
- ThereminGoat, Switch Oddities, Kinetic Labs, UniKeys, Milktooth, LumeKeebs, RGBKeys, ClickAndThock 등 해외 스위치 리뷰·판매처
- 스웨그키(swagkey.kr), 몬스타기어(monstargears.com) 등 국내 벤더 실시간 판매 확인
- arca.live 국내 커스텀 키보드 벤더 정리글

자세한 출처와 리서치 방법론, 각 세션별 작업 범위는 `switch-database-notes.md`에 기록되어 있습니다.

## 참고 사항

- 이 저장소는 커뮤니티 자료를 정리한 **비공식 참고 자료**이며, 각 제조사·판매처의 공식 정보가 아닙니다.
- 스펙·가격·재고 정보는 조사 시점(2026년 9월) 기준이며, 실제 정보는 변경될 수 있습니다. 구매 전 각 판매처에서 최신 정보를 확인하시기 바랍니다.
- 근거를 찾지 못한 항목은 추측 대신 "확인하지 못했다"고 명시하는 것을 원칙으로 했습니다.
