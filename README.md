# 스위치 아카이브 (Custom Switch Archive)

커스텀 키보드에 쓰이는 스위치들의 소재·스펙·타건 특성을 정리한 데이터베이스입니다. 국내(한국) 커뮤니티와 판매처 정보도 함께 넣어서, **어떤 스위치를 국내 어디서 살 수 있는지**까지 확인할 수 있습니다.

- **Claude 아티팩트 버전:** https://claude.ai/artifact/Vc2JSKB5KLD1zaDcj79GpP

## 스위치 번호

스위치마다 **브랜드 코드-순번** 형태의 고유 번호가 있습니다(예: `GAT-043`, `HMX-012`).

- 코드는 브랜드/제작사마다 알파벳 3글자입니다(GAT=Gateron, HMX=HMX, KLH=Kailh, CHR=Cherry …). 전체 코드표는 아카이브의 **용어·출처** 탭에 있습니다.
- 순번은 브랜드 안에서 영문 이름 ABC순(영문 → 한글 순서)으로 처음 한 번 매겼고, **이후 바뀌지 않습니다.** 새 스위치는 해당 브랜드의 마지막 번호 뒤에 이어 붙습니다.
- 검색창에 번호를 넣으면 바로 찾을 수 있고, 정렬을 "번호순"으로 두면 브랜드 코드별로 묶여 보입니다. 엑셀에서는 `no` 열입니다.

## 기능

- **스위치 DB** — 이름·브랜드·특주처·판매처로 검색하고, 브랜드·타입(리니어/택타일/클릭/마그네틱)·저소음·국내 판매·신규 추가 여부로 걸러볼 수 있습니다. 정렬 기준은 번호, 이름, 브랜드, 바닥압, 매끄러움, 안정성, 최근 추가 순입니다. 행을 누르면 상세 스펙, 국내 판매 정보, 참고 출처 링크가 펼쳐지고, 자료마다 값이 다를 때는 "출처 간 차이"가 따로 표시됩니다.
- **추천 도우미** — 타입, 선호 바닥압, 정숙성, 매끄러움, 브랜드, 국내 구매 가능 여부를 고르면 조건에 맞는 스위치를 점수순으로 추천합니다.
- **참고 탭** — 프랑켄 스위치, 스테빌라이저(설치·튜닝 팁 포함), 윤활제(도포 팁 포함), 소재별 특성 비교표, 제조사 소개, 국내 벤더 디렉토리
- 라이트/다크 테마 전환, 탭별 주소 공유(예: `#recommend`), 모바일 화면 대응

별점(접점부/스템 워블/서걱임/볼륨)은 원본 커뮤니티 위키의 상대 평가로, **Cherry MX Black을 기준점**으로 매겨져 있습니다. 새로 추가한 스위치에는 주관적 별점을 임의로 매기지 않고 비워 두었습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 아카이브 웹 페이지 |
| `data.js` | 페이지가 불러오는 데이터 (`window.SWITCH_DB`). `index.html`과 같은 폴더에 있어야 합니다 |
| `스위치_아카이브.xlsx` | 같은 데이터의 엑셀 버전 (스위치 DB 외 6개 시트) |
| `manifest.webmanifest`, `sw.js`, `icons/` | 앱으로 설치할 수 있게 하는 파일(아이콘·오프라인 캐시). 함께 올려두면 됩니다 |
| `switch-database-notes.md` | 작업 노트 — 데이터 출처, 조사 방법, 업데이트 이력, 한계점 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 배포하도록 하는 설정 파일 |

## 공유하고 실행하는 방법

서버는 필요 없고, 세 가지 방식 중 편한 걸 쓰면 됩니다.

1. **파일 하나로 보내기** — `스위치아카이브_단일파일.html` 하나에 데이터와 엑셀까지 모두 들어 있습니다. 메신저·메일·USB로 보내고, 받은 사람이 더블클릭하면 브라우저에서 열립니다. 인터넷이 없어도 동작합니다(글꼴만 기본 글꼴로 보입니다).
2. **웹 주소로 열기** — 이 폴더(`index.html`, `data.js`, `manifest.webmanifest`, `sw.js`, `icons/` 등)를 정적 웹 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 그대로 올리면 그 주소를 클릭해서 열 수 있습니다.
3. **아이콘으로 설치하기** — 2번처럼 `https` 주소로 올린 뒤 크롬·엣지에서 열면 화면의 **앱으로 설치** 버튼(또는 주소창 오른쪽의 설치 아이콘)이 나타납니다. 설치하면 바탕화면·시작 메뉴(휴대폰은 홈 화면)에 스위치 아카이브 아이콘이 생기고, 누르면 주소창 없는 앱 창으로 열립니다. 한 번 열어본 뒤에는 오프라인에서도 열리고, 온라인이면 뒤에서 최신 파일로 자동 갱신됩니다. iPhone은 사파리 공유 버튼 → "홈 화면에 추가"를 쓰세요.

로컬 파일(`file://`)로 연 화면은 설치형 앱으로는 등록되지 않습니다. 이때는 단일 파일을 그대로 쓰거나, 크롬 메뉴 → "저장 및 공유" → "바로가기 만들기"로 바탕화면 바로가기를 만들 수 있습니다(아이콘 모양은 기본 아이콘으로 나올 수 있습니다).

## 데이터 출처

- 기계식키보드 마이너 갤러리 정보글 & 스위치 데이터 문서 (커뮤니티 위키, 원본 데이터)
- 제조사 공식 스펙 페이지 (Gateron, Cherry, Kailh, Keychron, Varmilo, TTC, Wooting 등)
- switches.mx, ThereminGoat, Milktooth, LumeKeebs, Kinetic Labs, Click and Thock, ThockHub 등 해외 리뷰·데이터베이스
- 국내 판매처: 스웨그키, 몬스타기어, 체리 공식 스토어, 키크론 코리아, 다나와·쿠팡·11번가 판매 목록, 디지털포스트(PC사랑) 보도자료

스위치마다 참고한 출처 링크가 상세 화면과 엑셀의 `ref_urls` 열에 들어 있고, 상세 정보를 채운 스위치에는 어떤 출처를 기준으로 했는지(제작사 → 특주사(의뢰사) → 판매처 → 리뷰 → 커뮤니티 DB)가 `info_source` 열에 적혀 있습니다. 출처끼리 값이 다르면 기존 값을 덮어쓰지 않고 `data_note` 열에 따로 남겼습니다. 조사 방법과 한계는 `switch-database-notes.md`에 정리했습니다.

## 참고 사항

- 커뮤니티 자료와 공개 정보를 정리한 **비공식 참고 자료**입니다. 제조사나 판매처의 공식 정보가 아닙니다.
- 스펙·가격·재고는 조사 시점(2026년 9월) 기준이며 바뀔 수 있습니다. 구매 전에 판매처에서 확인하세요.
- 근거를 찾지 못한 항목은 추측하지 않고 "확인하지 못했다"고 적었습니다.
